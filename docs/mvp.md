# CalcDeck

**Objetivo:** calculadora científica 3D (inspirada na Casio fx‑82MS) para praticar. É um MVP em
evolução, ainda não 100% funcional.

**Tecnologias:** Vue 3, TypeScript, Vite, Three.js + TresJS, Tailwind CSS 4, Vue Router, Pinia,
Vitest, ESLint + Prettier.

**Atalhos:** `0-9 . ,` números · `+ - * / ^` operadores · `( )` parênteses · `Enter`/`=` calcular ·
`Backspace` apagar · `Esc` limpar · `!`/`%` fatorial e porcentagem · `s`/`c`/`t` seno, cosseno e
tangente · `r`/`l`/`n` raiz, log e ln · `p`/`a` π e Ans · `h` hiperbólico · `F9` trocar o sinal.
