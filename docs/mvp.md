# CalcDeck

## Objetivo

Praticar com calculadoras científicas virtuais em 3D, reproduzindo a interface e o funcionamento do
modelo físico (inspirado na Casio fx‑82MS). É um MVP em evolução, ainda não 100% funcional.

## Tecnologias

- Vue 3 + TypeScript
- Vite
- Three.js + TresJS
- Tailwind CSS 4
- Vue Router
- Pinia
- Vitest
- ESLint + Prettier

## Atalhos

| Tecla                   | Ação                        |
| ----------------------- | --------------------------- |
| `0`–`9`, `.`, `,`       | Números e separador decimal |
| `+`, `-`, `*`, `/`, `^` | Operadores                  |
| `(` e `)`               | Parênteses                  |
| `Enter` ou `=`          | Calcular                    |
| `Backspace`             | Apagar                      |
| `Esc`                   | Limpar (AC)                 |
| `!`, `%`                | Fatorial e porcentagem      |
| `s`, `c`, `t`           | Seno, cosseno e tangente    |
| `r`, `l`, `n`           | Raiz, log e log natural     |
| `p`, `a`                | π e Ans                     |
| `h`                     | Alternar modo hiperbólico   |
| `F9`                    | Trocar o sinal              |
